# BTL CO3009 - Hệ thống đèn giao thông hai tuyến

## Thông tin dự án
- Môn học: Vi xử lý - Vi điều khiển (CO3009).
- Phần cứng: XNUCLEO-F103RB, chip STM32F103RB.
- Công cụ: STM32CubeIDE.

## Quy ước làm việc
- main: phiên bản ổn định.
- dev: tích hợp phần việc của cả nhóm.
- feature/<ten-chuc-nang>: phát triển từng chức năng.
- Tệp tự viết dùng chữ thường và dấu gạch dưới:
  scheduler.c, software_timer.c, fsm_automatic.c.
- Commit mô tả rõ thay đổi, ví dụ:
  scheduler: add one-shot task support.
- Mỗi thành viên tự commit phần việc của mình.

## Hướng dẫn build và nạp
Sẽ bổ sung sau khi tạo và kiểm thử dự án STM32CubeIDE.
